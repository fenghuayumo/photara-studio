# 独立子图重建与验证后重新对齐

2026-09-06 后续增加了结构风险驱动的前端补匹配，并以 ori_img 替换 lego1 做回归；新结果见 [SFM_ACCEPTANCE_20260906.md](../docs/SFM_ACCEPTANCE_20260906.md)。下文保留首次独立子图实验的结果。

本阶段增加了可执行的几何恢复实验路径，不再只计算结构风险。**合成漂移已经能够恢复；Alameda 的真实漂移仍未修正，整体提速仍未验证。** 新入口未接入默认 mapper，未修改结构审计的可靠性判定，也不把“局部重建成功”计作“全局对齐成功”。

## 实现与接受条件

`aetherscan_sfm_realign` 只读加载明确指定的 reconstruction checkpoint，先执行原有最终观测筛查和结构审计，冻结主体相机名单，再按非主体相机之间的有效配对连接提取候选子图。不会自动将后来恢复的支路作为其他支路的对齐基准。

- 子图仅复制关键点、内部已验证配对和当前内参；清空原位姿、三维点、tracks 和注册状态，重新建立 tracks、执行 star 初始化和增量注册。内参固定，因此这是独立的局部几何求解，不是独立的相机标定或前端重新匹配。
- 主体侧深度从至少两个不同主体相机的观测重新三角化，不使用旧三维点坐标，也不使用支路相机求主体深度。最小视差 1°，最大重投影误差 2 px；重合视点无法提供深度。共享点同时利用原轨迹观测身份及有效边界配对，拒绝非一对一关联。
- 至少 30 个独立共享点；确定性地留出每五个点中的一个，仅用其余点拟合正尺度、无反射的 Sim(3)。拟合和留出点通过率均须达到 80%。三维阈值为拟合主体点相对均值距离中位数的 1%，并检查拟合点、内点及留出点的非共线性。
- 留出点同时通过三维残差和在局部观测中的正深度、2 px 重投影检验，至少覆盖两个局部相机。所有局部相机必须完成注册，写回前每个相机至少保留 30 个不同特征的有效观测。
- 写回只改变通过验证的子图位姿，并重建受影响轨迹；主体相机位姿和内参不优化。受影响点不能丢失主体侧原有的有效重投影支持。任何几何拒绝保留旧位姿和轨迹，后置支持门槛失败也会回滚候选位姿。

这些是可配置的保守工程门槛，不是准确性证明。留出点未参与 Sim(3) 拟合，但参与了各自地图的局部重建；当前实现不是留出图像的独立验证。只有一两个相机的候选组暂不进入该路径，需要另外的主体地图 2D–3D 重定位策略。

## Alameda 结果

输入：`artifacts/sfm_acceptance_20260905/cache/alameda/reconstruction-bdd89e87a4956da8.bin`。

原模型筛查后注册 1701/1734，主体 1671，结构风险相机 30。非主体有效配对形成 12 个候选组。其中 `indoor_DSC07344.JPG`–`indoor_DSC07359.JPG` 共 16 个相机，包括原先定位的 15 相机漂移支路及边界相机。

| 检查 | 结果 |
| --- | ---: |
| 独立注册 | 16/16 |
| 局部三角化点 | 3876 |
| 有效边界配对匹配 | 159 |
| 可关联局部点的父轨迹候选（含纯局部轨迹） | 3600 |
| 候选中具备至少两个不同主体相机观测的轨迹 | 0 |
| 双侧独立共享三维点 | 0 |
| 接受重新对齐的相机 | 0 |

拒绝原因为 `insufficient_independent_shared_points`。其余 14 个风险相机属于大小为 1 或 2 的组，返回 `too_few_local_views`。所有相机坐标保持不变，不能把这一结果描述为漂移修复，也不能用局部运行时间声称端到端加速。局部模型仅证明该次求解完成，尚未认证它的参考轨迹精度。

输出保留 `independent_2.asfm`（拒绝全局对齐的独立局部模型）、`members.csv`、`submaps.csv`、`poses.csv` 及 `reconstruction.asfm`。`poses.csv` 的 `stable` 是本轮冻结的输入掩码，不代表新计算的几何可靠性。最终模型仍含不确定支路，应连同 CSV 使用。

最终证据目录为 `artifacts/sfm_acceptance_20260905/alameda_submap_recovery_v3/`，相邻 `.run.json` 保存输入 SHA-256、执行文件 SHA-256、退出码 2 及墙钟 15.26 秒。该时间包含缓存读取、审计、局部恢复和输出，**不是完整 SfM 耗时**。`consistency.json` 校对输入相机中心与既有 `alameda_independent_depth` 诊断，并确认输出最大位移为零。

现有证据将下一步收敛到**增加可验证的跨图观测**：针对支路及边界图像向主体图像检索、补匹配并严格验证，优先寻找能落到主体多视图 landmark 上的对应；随后再次执行独立子图对齐，或单独实现经几何验证的主体 2D–3D 重定位。只增加单桥上的匹配数，未必能产生主体侧独立深度。证据不足时继续保留不确定状态。

## 复现

```powershell
cmake --build build --config Release --target aetherscan_sfm_realign aetherscan_submap_recovery_test -j 4
build/aetherscan/Release/aetherscan_sfm_realign.exe `
  artifacts/sfm_acceptance_20260905/cache/alameda/reconstruction-bdd89e87a4956da8.bin `
  artifacts/sfm_acceptance_20260905/alameda_submap_recovery_v3
ctest --test-dir build -C Release --output-on-failure -R 'sfm.(submap_recovery|mapping|hierarchical)'
```

每次使用新输出目录；已有目录拒绝覆盖。进程退出码：0 表示所有输入风险相机均通过此恢复路径（无风险相机时也为 0），2 表示仍有未恢复组，1 表示输入或执行错误。它不读取 COLMAP 参考，不写输入 checkpoint，不执行完整前端或全局重建。`submaps.csv` 耗时只覆盖每组恢复及局部证据导出，不包含 checkpoint 加载、初始审计和最终模型导出。

回归覆盖：清空旧状态与排除边界配对、已知漂移恢复且主体位姿精确不变、缺少共享点拒绝、错误跨图对应拒绝、共线点拒绝、重合主体视点拒绝、留出点失败拒绝、后置观测门槛回滚、重复图像 ID 拒绝。既有 mapping 和 hierarchical 测试一并执行。

最终验证：上述 C++ 测试 3/3 通过；Python 验收测试 5/5、图审计测试 3/3 通过。
