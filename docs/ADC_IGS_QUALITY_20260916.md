# ADC-IGS 无颜色校正质量验证（2026-09-16）

## 目标和基线

在用户清理后的 `eac3a91` 基础上，提升关闭 PPISP 和双边网格时的基础质量。
保留当前 ADC+ 协方差分裂、200 步细化、阈值增长预算和 IGS 评分。
按用户要求测试 15,000 步，100 万高斯上限，固定每 8 张留出一张。

- 室内：`D:/BaiduNetdiskDownload/室内iphone`，645 训练 / 93 留出，1280×1920。
- bicycle：`D:/Models/360_extra_scenes_1/bicycle/images_2`，使用同级 `sparse/0`，
  图像 2473×1643；PPISP、双边网格、mask、渐进分辨率、深度/多视角损失均关闭。

## 初始化改动

`initialize_from_dense_cloud` 原来把 ADC+ 和 ADC-IGS 的初始 opacity 都强制设为 0.5，
忽略 IGS 的 `TrainingOptions::initial_opacity`（默认 0.1）。现在 IGS 使用该已有设置，
ADC+ 保持 Brush 的 0.5。尺度、四元数和其他训练策略不变，没有新增 CLI 参数。

目的：减弱稀疏初始化时的过早遮挡，让后方表面获得梯度，而非增加硬剪枝或在后期
普遍压低已学好的 opacity。回归测试检查默认/显式 opacity、ADC+ 的原有初始化，
并确认 IGS 的尺度和旋转未被改变。

## 已完成的室内对照

同为关闭 CUDA 图像缓存和预取的 15k 运行：

| 配置 | 留出 PSNR | 留出 SSIM | 平滑区带通误差 | 相对带通误差 | 对齐后 PSNR |
|---|---:|---:|---:|---:|---:|
| 当前基线，初始 opacity 0.5 | 22.4344 | 0.948895 | 0.005988 | 0.649727 | 23.6105 |
| IGS 使用初始 opacity 0.1 | 22.6099 | 0.949289 | 0.005612 | 0.611600 | 23.7706 |

PSNR +0.1755 dB，SSIM +0.000394；带通误差下降约 6.3%。两个模型均为 100 万高斯。
近相机相对距离 <0.5 的高斯数 79→51，opacity 总和 4.7028→2.5952；这是风险代理量，
不是真实漂浮物计数，也不意味着所有雾团已经消除。

93 视角 canonical 指标来自训练器最终评估；带通误差和逐通道增益/偏置对齐指标
来自固定 12 个视角 `0,64,...,704`，不能和 93 视角的原始 PSNR 混比。
逐视角颜色拟合仅用于诊断，训练和导出模型均未启用颜色校正。

2473×1643。全部留出视角结果：

|---|---:|---:|
| 当前基线，初始 opacity 0.5 | 24.1268 | 0.726438 |

PSNR +0.0663 dB，SSIM +0.004799。目视检查 view 0，自行车车架、辐条和长椅
保持清晰；背景植被与画面边缘仍有明显模糊块，初始化改动并未解决全部问题。
固定 4 视角的独立诊断使用最长边 1920，不能与上述全分辨率指标直接比较。
该组原始图像 PSNR 24.5026→24.5223，SSIM 0.719826→0.722234；
带通误差 0.0100964→0.0100173，对齐后 PSNR 24.8021→24.8490。
植被场景的带通误差不能直接解释成漂浮物多少。

## 验证与结论

Release 编译成功；`photara_splat_test.exe --igs-only` 通过（含新增初始化回归检查），
Python 实验脚本语法检查和修改文件的 `git diff --check` 通过。
保留这项小改动：两个场景的留出指标均改善，室内雾团相关代理量也改善。
这是有限的基础质量提升，不能替代颜色校正，也不能宣称消除了漂浮物。

## 未采用的候选

曾尝试用第二强的不同相机几何梯度代替最大梯度作为增殖门槛。
回归测试通过，但 7k 时 PSNR 21.9217→21.8782，带通相对误差 0.664550→0.703336。
15k 候选为 22.3353 / 0.949324；与相同无缓存配置的基线相比 PSNR 仍较差。
该实现及其测试已撤回，实验补丁保存在 `artifacts/igs_quality_20260916/two_view_geometry.patch`。

## 运行限制和复现

原配置在修改前基线和候选上均出现过 `illegal memory access`，仅关闭预取仍失败。
最终成对测试统一使用 `--splat-prefetch-views=0 --splat-cache-auto=false
--splat-device-cache-mb=0`，没有改动缓存实现，不能据此声称根因已经查明。
原缓存配置的室内基线曾达到 22.6557；运行配置不同且有 CUDA 波动，不用于本轮增益计算。

实验目录：`artifacts/igs_quality_20260916/`。独立二进制在 `bin/`，各运行保存命令、
日志、PLY、留出渲染和诊断图；快速脚本支持 `--images` 指向 `images_2`，并记录二进制哈希。
目前数字为单次成对结果，不能据此保证所有场景都会获得同等收益。
