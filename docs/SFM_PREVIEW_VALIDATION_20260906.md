## 算法与接受条件

弱连接相机尝试向主体地图进行 2D–3D 重定位。锚点深度由冻结的主体相机独立三角化，不继承漂移支路的旧三维坐标。特征与轨迹一一对应；至少 40 个候选对应；拟合使用其中 80%，其余用于留出验证。拟合与验证均要求至少 80% 支持、2 px 重投影阈值，并检查非共线几何及图像空间覆盖。证据不足时不写回位姿。验收还允许独立主体深度支持充足的单相机通过几何审计，无需它独自形成可三角化子图。

这不能保证找回缺少主体共同可见点的相机，也不能将图中有环直接解释为坐标正确。现有独立子图恢复和结构补匹配实验的限制仍然有效。

## 过程预览

CLI 在传入 `--working-sfm` 时发布独立的 `.preview.asfm`；编辑器的对齐命令已传该参数。全局模式在首次三角化、BA 后及最终重建阶段发布，回调最短间隔 3 秒，并非每 3 秒都有新几何。增量模式复用注册检查点回调。

每份快照上限 30,000 个点，保留相机，压缩观测索引，不带描述子或配对图。先写临时文件再原子替换。编辑器每 500 ms 检查更新，异步读取；预览不重复解码原照片着色。首次自动取景，后续保留用户视角。加载正式结果后退出部分结果状态；取消或失败留下的预览仍显示 `PARTIAL ALIGNMENT / NOT FINAL`。

特征提取及匹配尚无有效三维几何时仍显示等待状态。临时注册数可能在后续质量过滤时下降，不能当作最终成功数。
