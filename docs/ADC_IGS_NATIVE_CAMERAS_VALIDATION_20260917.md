# ADC-IGS 最新改动复测（2026-09-17）

## 结论

**代码回归通过、整体画质保持，但重建稳定性未完全通过。** 全景反传与 mask 改进有效，
本轮没有复现原来遍布人物遮挡位置的大气泡；鱼眼均值略有提升。然而同一版本、同一命令
重复训练时，全景 view 344 出现明显灰雾，下降约 4.9 dB；因此不能仅凭均值稳定宣布质量 OK。
独立加载导出 PLY 重渲染，灰雾图逐像素完全一致，问题已进入模型。

## 回归测试

Release 编译及完整 `photara_splat_test.exe` 通过。
全景有限差分 4 个位置、3 个轴的最大相对误差约 0.69%，含接缝、近景及高仰角。

本轮另补充 `check_color_only_parity`：在针孔、鱼眼和全景中比较开启/关闭几何工作区
对应的 RGB、alpha、位置、尺度、旋转、不透明度与 SH 梯度。颜色路径传入空深度/法线
梯度，检查无几何图像分配；容差为绝对 1e-6 加相对 1e-4。
这验证 RGB 路径的等价性，不代表全景非零深度损失已验证。
新增检查编译后，`--fisheye-only` 及完整测试均通过；最终完整日志为 `final_tests.log`。
本轮只添加回归测试和实验报告，没有改变用户的训练策略及性能实现。

## 重复运行：平均值掩盖单视角失稳

同一冻结二进制、同一参数，全部重新训练 15k：

| 指标 | 第一次 | 重复运行 |
|---|---:|---:|
| 训练器静态 PSNR | 26.5209 | 26.5189 |
| SSIM | 0.860048 | 0.859293 |
| PNG 静态 PSNR | 26.975578 | 26.976457 |
| PNG 球面静态 PSNR | 26.400555 | 26.373282 |

平均 PNG PSNR 差只有 +0.00088 dB，但逐视角绝对差均值为 0.405 dB。
最初重点检查的 view 72 / 272 从 27.353 / 28.117 回升到 28.530 / 29.169，
说明这两个视角的下降不是在此次重复中稳定复现的。

**新的严重异常：view 344，`05172.jpg`。** PNG 静态 PSNR 第一次 23.3154，
重复运行 18.4120，下降 4.9034 dB；主体布局仍在，但画面覆盖灰色雾层。
重复运行的训练器静态曲线：1k 21.8333 → 5k 23.2509 → 10k 20.3222 → 15k 18.3080。
延长训练并未修复该视角，反而进一步变差。

使用最新版 `photara_splat_quality_eval.exe` 独立读取重复运行的导出模型，
对 view 344 重渲染，和训练器输出的 8-bit RGB 最大像素差及平均差均为 0。
所以不能归因于临时评估缓冲或保存图片；也不能仅凭两次训练定位到具体哪个 kernel。

## 验收建议

1. 保留已验证的全景反传和遮挡 mask 设置；本场景明确使用 masked + alpha leak=0。
2. 把全景 view 344 的 5k/10k/15k 曲线及重渲染作为雾团回归案例，优先调查后期模型失稳。
3. 同时报均值、逐视角退化及最差区域；全景平均 PSNR 几乎相同仍可出现严重坏视角。
4. 当前证据支持基础代码正确性和整体质量维持，不支持“两个场景都已稳定优化好”。

三次训练全部正常退出，最终高斯数为全景 1M / 鱼眼 2M。测试和比较完整记录位于
`artifacts/native_camera_20260917/`，本轮未验证性能增益，不将墙钟时间直接与并发旧实验比较。
