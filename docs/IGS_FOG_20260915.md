# ADC-IGS 室内雾团修正

数据：`D:/BaiduNetdiskDownload/室内iphone/sparse/0`，图像来自同级 `images`。

## 代码改动

1. 补位、按权重采样的大高斯分裂、直接大高斯分裂及普通增殖，统一使用
   `growth_eligible`。IGS 开启几何梯度门槛时，所有路径都要求至少两个不同
   相机有贡献，且几何梯度超过门槛。此前补位和大高斯路径会绕过几何门槛。
2. 低透明度证据剪枝改用不同相机支持数，避免同一相机反复采样被误当作
   多视角支持。短窗口内完全没被观察到的高斯保留，避免因房间覆盖不均
   而误删。原有透明度、非有限值等基础剪枝仍然执行。
3. 这些调整仅改变 ADC-IGS 的行为；ADC+ 的既有门槛保持原意。
4. 第二轮在 IGS 预设中加入 opacity 正则 `0.005`、log-scale 正则 `0.01`。
   CLI 仅在用户显式指定时覆盖策略预设，因此仍可以传零关闭。已有正则
   CUDA 实现未改动；这轮测试检验预设启用效果。

这不是显式空域约束：两个相机可能很接近，贡献也不代表真实表面。
几何梯度门槛限制的是复制需求，不是对三维几何正确性的证明。

## 回归验证

`aetherscan_splat_test.exe --igs-only` 已通过，新增测试覆盖：

- 低几何梯度的高斯不能通过补位或大高斯路径增殖；
- 采样大高斯预算有剩余时，不能分配给不满足几何门槛的父高斯；
- 低透明度单相机重复贡献应剪枝，未观察、多视角支持和较不透明的行保留；
- 剪枝后模型与 Adam 状态行数一致。

## 数据集验证口径

按用户要求，后续使用 7,000 步快速判断早期结构问题。修改前、修改后使用相同
训练步数、100 万高斯上限、固定 1/8 留出划分（645 训练 / 93 留出），关闭
mask、渐进分辨率与深度/多视角辅助损失。直接配置 7,000 步会改变依赖总步数
的学习率和噪声衰减，因此应比较这对 7k 运行，不能把它当作 30k 运行的原样截断。

`run_ab.py --sampled-novel` 只减少新视角诊断图片的保存数量，全部留出指标不变。
相机近邻统计只是漂浮风险的代理指标，需结合相同相机位置的新视角图像判断。

实验目录：`artifacts/igs_fog_20260915/`。保留修改前的 30k 完整参考；修改后的
30k 尝试已按用户要求中止，不作为有效最终结果。
