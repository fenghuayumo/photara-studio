# SfM 全分辨率弱支路塌缩诊断（2026-09-06）

背景：`SFM_ACCEPTANCE_HALFRES_20260906.md` 记录了 alameda 全分辨率失败（两段支路
40-61% 漂移）、半分辨率通过。本文用配对级证据定位失败机制。原验收 artifacts 目录
在本会话外被清空，本文证据来自重跑的 `artifacts/sfm_branch_diag_20260906/`；期间
仓库正被并行修改（splat 相关文件），本文未改动任何源码。

## 根因链条

### 1. 检索与匹配都能找到跨支路连接，不是召回问题

全分辨率 pairs CSV（10,512 行）中，07344-07359 支路内部有 70 条活跃边、内点
30-670，内部连接充分。跨分量候选边也存在且几何验证通过，但被停用：

| 边 | 内点 | ray 角 | geometry | connectivity | triplet | composite | active |
|---|---:|---:|---:|---:|---:|---:|---:|
| 07350-07427 | 62 | 29.1 | 1 | 0 | 0 | 0 | 0 |
| 07351-07330 | 34 | 0.0 | 1 | 0 | 0 | 0 | 0 |
| 07355-07360 | 28 | 4.8 | 1 | 0 | 0 | 0 | 0 |
| 07359-07412 | 22 | 14.9 | 1 | 0 | 0 | 0 | 0 |
| 07359-07360（唯一存活桥） | 159 | 4.5 | 1 | 1.0 | 0.17 | 76.2 | 1 |

这些边 `degenerate_planar=0`、`zero_baseline=0`、`geometry_weight=1`，被杀的直接
原因是 connectivity/triplet 支持为 0 导致 composite weight 为 0（前端对有效配对
存在约 3.0 的 composite 权重使用门槛）。triplet 支持需要相邻边先存活；邻近边失败
后 cycle/triplet 支持连锁归零，连 62 内点的健康边也被清掉——鸡生蛋式塌缩。最终
16 相机支路只靠 07359-07360 单桥悬挂，误差从桥端向末端累计到 55-63%。

### 2. 全分辨率在弱纹理区域的每对内点数大幅劣化

同一条边、同一算法、同一数据集，仅分辨率不同：

| 边 | 全分辨率 | 半分辨率 |
|---|---|---|
| 07359-07360（支路主桥） | 159 内点，w=76.2 | 604 内点，w=755.0 |
| 07477-07478（叶子边） | 193 内点，triplet=0 | 787 内点，triplet=0.375 |
| 07524-07525 | planar=1，w=0.35 | planar=0，w=67.96 |

支路相机的活跃图度数：全分辨率 2-6，半分辨率 3-17（中位约 4.5 对 7.5）。全局
中位内点相近（163 对 175），劣化集中在弱纹理支路：全分辨率 SIFT 描述子在这些
区域配对存活率骤降，使跨分量边低于支撑门槛。半分辨率下同样的边内点数约为
4 倍、triplet 支持存在，支路自然连回主体。

### 3. 叶子相机模式

07477 仅有一条边（07477-07478，193 内点、w=75.4）但 ray 角 1.97 度，单边近平面
几何使相机中心沿视线弱约束，位置误差 58.3%。该相机已被对齐可观测性审计标记，
检测正确、位置仍错——检测与修复是两件事。

## 修复建议（按优先级）

1. **停止硬杀跨分量几何有效边**：配对加权后计算连通分量；对 `geometry_weight>0`、
   内点达标、非零基线的边，若其激活能连接不同分量或消除桥，用保守权重下限恢复
   而非保持 0。两视 RANSAC 已验证的边不应因邻近边失败被连锁清除；风险继续由
   对齐可观测性审计暴露。这与已失败的 `--sfm-structural-rescue` 不同：不新增
   匹配，只恢复"已验证但被加权塌缩"的边，且不移除风险标记。
2. **分辨率自适应前端**：全分辨率下对弱纹理区域放宽 ratio/阈值，或用半分辨率
   特征构建匹配图、全分辨率观测参与 BA 的双尺度前端。07359-07360 从 159 到 604
   内点说明提升空间明确。
3. **叶子/单桥相机处理**：位置接受要求两条以上独立加权边，否则输出低置信度；
   07477 类相机由审计标记升级为产品级拒收或隔离。
4. **前端可复现性**：两轮全分辨率运行的失败位置不同，检索候选存在运行间随机性
   （vocabulary 训练/种子）。验收与回归应固定候选缓存或种子，避免把随机波动误读
   为修复/退化。
