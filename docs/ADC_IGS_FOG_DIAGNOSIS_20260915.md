# ADC-IGS 雾团（cloudy block）诊断与消融

数据：`D:/BaiduNetdiskDownload/室内iphone`（738 张 iPhone 照片、222,484 稀疏点、
3 个 OPENCV 相机）。所有本轮 A/B 都在 7,000 步、1,000,000 高斯上限、
固定 1/8 留出（645 训练 / 93 留出）、关闭 mask、关闭渐进分辨率与深度/多视角损失的
口径下运行；每个配置单独记录二进制哈希与命令。

留出指标取自训练器自身的 93 视角评估（与独立评估器同一代码路径、同一分辨率）。
图像诊断另外用 `--sampled-novel` 与 1/64 视角重渲染，只用来算 8-64 px 中频结构误差
和看画面，不作为指标口径。

## 用户观察到的现象

ADC-IGS 结果里某些平滑区域（天花板、地面）会出现成块的云状明暗，像高斯聚成一团漂浮物；
7,000 步就能看出，之后基本不消失。

## 与同数据集参考实现的直接对照

该数据集自带 spirula-studio（`preset: "3dgs"`）的 30,000 步 `splat.ply`。用本仓库的
评估器重渲染后，同一相机（view 64）的天花板是干净的、梁边锐利；本仓库 7k 与 30k
两个模型在同一位置都有明显云团，且梁边被糊掉。因此这不是数据、相机模型或光栅化器
的问题，而是我们训练管线产生的假结构。

同一 ROI（1280×1920 帧的 `100,60,1180,420`，view 64）内覆盖该区域的高斯：

| 模型 | 高斯数 | opacity 总和 | 屏幕半径 p50 | max scale p50 |
|---|---:|---:|---:|---:|
| spirula-studio 30k | 699 | 94.0 | 31.9 px | 18.1 mm |
| 本仓库 7k（默认） | 1715 | 480.4 | 25.0 px | 11.1 mm |

我们把 2.4 倍数量的高斯、5 倍的不透明度质量堆在同一片平滑区域上，每颗自身的 alpha
更高（≈0.28 对 ≈0.13），于是画面由少数几层主导，个体颜色差异就显形成云。

## 排除的假设

| 假设 | 检验 | 结果 |
|---|---|---|
| 训练图像里本来就有云 | 取相邻 6 帧（56/64/72/80/88/96）的同一天花板区域 | 每帧内部都平滑，只有整体亮度漂移（均值 142→175，约 ±10%） |
| 视角相关 SH 颜色造成 | 把 PLY 的 `f_rest_*` 全部置零后重渲染 | 云的形状与强度几乎不变，排除 SH 主导 |
| 单纯 alpha 合成问题 | 只把该 ROI 内高斯的 alpha 降到 35% 后重渲染 | 云的**结构**仍在（只是整体变淡/变暗），说明高斯自身的 DC 颜色就带云 |
| coarse-to-fine（渐进分辨率） | 该口径下本来就关闭；显式打开做对照 | 打开后 7k PSNR 21.62（+0.14 dB），中频结构误差略降（0.0062 对 0.0069），但不是造成雾团的原因 |

剩余解释是拍摄端逐帧曝光/白平衡漂移（11.6% 相对亮度标准差、HDR 与非 HDR 混拍）。
关闭颜色校正时，模型只能把"同一表面在不同帧里亮度不同"这件事摊到不同高斯的颜色上，
在过绘制的平滑区域就表现为云团。参考实现的配置里 `use_ppisp: true`、
`use_bilateral_grid: true`，正好把这部分变化交给颜色校正承担。

## 消融结果（7,000 步）

留出 PSNR/SSIM 为 93 视角的 canonical 指标；“中频结构误差 relative”和“对齐后 PSNR"
在 12 个共同视角（0,64,…,704）上计算，因此与 93 视角数值不可直接相比，只用于横向比较。

| 配置 | 留出 PSNR | 留出 SSIM | 高斯数 | 中频结构误差(相对) | 对齐后 PSNR |
|---|---:|---:|---:|---:|---:|
| 默认（本轮基线，SH 正则已关闭） | 21.4839 | 0.942502 | 989,108 | 0.807 | 22.940 |
| + 渐进分辨率（coarse-to-fine 打开） | 21.6215 | 0.941365 | 943,060 | 0.756 | 22.983 |
| + 渐进分辨率 + 初始 opacity 0.1 | **21.6433** | 0.941464 | 947,522 | 0.727 | 22.987 |
| + 初始 opacity 0.1 | 21.6025 | 0.943096 | 987,849 | 0.800 | 22.972 |
| + opacity/scale 正则（0.005 / 0.01） | 21.4364 | 0.942015 | 964,171 | 0.861 | 22.765 |
| + PPISP `no_crf_no_vig` | 21.2912 | 0.942919 | 991,402 | 0.778 | 23.628 |
| + 渐进分辨率 + PPISP | 21.4509 | 0.941815 | 946,332 | **0.705** | **23.761** |
| + 双边网格 | 20.6895 | 0.941368 | 983,419 | 0.856 | 22.466 |
| + PPISP + 双边网格 | 21.0130 | 0.942982 | 993,168 | 0.688 | 23.488 |
| + 长轴分裂（`--splat-long-axis-split`） | 21.3017 | 0.940426 | 1,000,000 | 0.949 | 22.674 |
| spirula-studio 30k（参考，30k 且非同一命令） | 22.1409 | 0.9501 | 994,506 | 0.460 | 24.874 |

说明：

- “中频结构误差”= 目标图像局部平坦（梯度最低 35% 像素）区域内，3-32 px 带通残差
  的均值（`experiments/igs_fog_metric.py`）。它只描述"平滑表面上多出来的结构"，
  不是漂浮物计数，也不能跨数据集比较。
- “对齐后 PSNR”= 每个留出视角各拟合一组逐通道增益/偏置后再算 PSNR，用来把拍摄端
  曝光差异从比较里去掉；它不是导出模型的 canonical 指标。
- PPISP 让 canonical PSNR 掉 0.19 dB，但对齐后 PSNR 提升 0.69 dB，并且画面上的云团
  明显减少（见 `artifacts/igs_fog_20260915/report_compare/ceiling_ppisp_sheet.png`
  与 `ceiling_round4_sheet.png`）。这与本仓库早先在 antman/WeChat 上"颜色校正提升
  对齐质量、降低 canonical 指标"的结论一致。
- `--splat-initial-opacity 0.1` 是本轮唯一同时提升 canonical PSNR 与 SSIM 的单项改动
  （+0.12 dB / +0.0006），但它不改变中频结构误差，也就是不解决雾团。
- 单项里的最高 canonical PSNR 是"渐进分辨率 + 初始 opacity 0.1"（21.6433，+0.16 dB），
  它的中频结构误差也略优于基线（0.727 对 0.807）。愿意用 canonical PSNR 换画质时，
  "渐进分辨率 + PPISP"把结构误差压到 0.705 且对齐后 PSNR 高 0.82 dB，代价是
  canonical −0.03 dB。
- 长轴分裂、双边网格、opacity/scale 正则三者在 canonical 与对齐指标上都是负收益，
  不能作为"减少雾团"的候选。
- 即便最好的一档（渐进分辨率 + PPISP）也只把相对中频结构误差从 0.807 降到 0.705，
  参考实现是 0.460，仍然没有追平。

## 还没有定论的

- `--splat-long-axis-split`（参考实现的 `use_long_axis_split`）仍未跑对照；它更接近
  参考实现的分裂方式，但雾团看起来更偏外观/alpha 而不是分裂几何。
- 训练分辨率（我们 1920，参考 2560）未在本轮口径下复核。
- 尚未复现参考实现的 `erank_reg` / `max_gauss_ratio` / `quat_norm_reg` 等整栈正则，
  因此不能声称"我们已经追平参考质量"。

## 本轮代码改动

- ADC-IGS 预设不再默认打开 SH 正则（`sh_regularization_weight` 保持 `0`，仍可用
  `--splat-sh-*` 显式开启）。
- `--splat-progressive-resolution` 在稀疏输入下会被**尊重**：此前稀疏分支无条件把
  渐进分辨率关掉，用户显式传 `true` 也会被静默丢弃；现在只有默认值被改写。
  `--splat-sh-degree-interval` 这类只为本轮对照临时加的参数没有保留。
- 新增 `--splat-initial-opacity W`（显式覆盖 ADC 的 brush 0.5 初值）与
  `--splat-long-axis-split`（ADC-IGS 使用长轴分裂 mode 6）。
- `add_geometry_regularization` 的 scale 先验改为对**线性尺度**求导
  （`d mean(exp(log s)) / d log s`）。此前的常数 log-scale 梯度在 Adam 的逐坐标
  归一化下会把没有数据支撑的轴压到 `exp(-40)`，实测产生 1e15 量级的各向异性针状
  高斯；同一权重下线性形式把 p99 轴比从 7.7e11 降到 95。
- 回归：`aetherscan_splat_test.exe`（含 IGS 子集与新增的几何正则解析梯度/覆盖检查）
  通过；`git diff --check` 通过。
